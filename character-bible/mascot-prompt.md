# Mascot Generation Prompt

**Character:** the narrator peacock (see `style-guide.md`) — third design
iteration. Myna was rejected as too dark/moody; parrot was rejected as not
striking/beautiful enough. Peacock directly answers the brief: "feathery,
beautiful, a colour-goddess type icon people stop scrolling for." Stays a
majestic *animal* character, not a deity — keeps the channel's religious-
depiction boundary intact.
**Composition:** turnaround / model sheet (front, 3/4, side, back)
**Style:** classic fairy tale book illustration (painterly, whimsical) — see
`style-guide.md` for the full art-style rationale
**Model used:** Nano Banana Pro (Google, via Higgsfield, or directly) — chosen
because it accepts `image_references`, so this exact output image can be fed
back in as a reference on every future mascot shot, rather than re-describing
it from text each time.
**Aspect ratio:** 16:9
**Resolution:** 2K recommended (1K to save cost, 4K is overkill for a Shorts asset)
